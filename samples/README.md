# Samples

Four files from the real project, unchanged apart from the header on
`layout-check.js`. They import files that are not in this repository, so they
are for reading, not running.

| File | What it shows |
|---|---|
| `detmath.js` | Maths that gives the same answer in every browser, which live play depends on |
| `rng.js` | A seeded random number generator whose state is saved with the fight |
| `clash.test.js` | Unit tests for Clash fights, including exact replay of a mid-flight action |
| `layout-check.js` | The automatic layout fault finder used by the browser tests |
